# Seed Growth 016 — Compact Semantic Stability

## Classification

Exploratory fresh compact-semantic-stability ablation.

## Question

Was Seed Growth 015's single compact semantic failure evidence of a
systematic representation weakness, or ordinary stochastic variation
in transfer-model behavior?

## Motivation

Seed Growth 015 deterministically reduced model-visible memory by
approximately 46.7% while preserving:

- exact semantic evidence visibility;
- complete-lesson performance;
- zero unsupported claims.

Its single live run produced:

- verbose: 20/20 semantic task success;
- compact: 19/20 semantic task success.

The compact failure retained the exact required evidence but the
transfer model omitted a scope word in its free-text answer.

Therefore the next question is not whether evidence was lost.

It is:

> Does compact representation systematically reduce behavioral
> reliability?

## Principle

A single stochastic model output should not cause a new architectural
mechanism to be introduced.

Repeated independent transfer trials should distinguish:

- representation failure;
- model-output variance.

## Conditions

Both conditions use:

- identical raw evidence;
- identical initial extraction;
- identical repair;
- identical structured admissions;
- identical grounded fallback records;
- identical transfer tasks;
- identical model.

### Condition A — Verbose

Seed 014 lossless semantic representation.

### Condition B — Compact

Seed 015 deduplicated evidence-index representation.

No additional extraction, repair, projection, or compression model call
is introduced.

## Replication

Each family receives three independent transfer attempts under each
condition.

20 families × 2 conditions × 3 attempts = 120 transfer calls.

Initial extraction occurs once per family.

Repair occurs once per family.

## Independence

Each transfer replicate runs in a fresh SQLite database.

Thus:

transfer attempt 2 cannot retrieve the decision generated by transfer
attempt 1.

Every replicate begins from the same learned memory state.

## Primary Metrics

### Per-call semantic pass rate

Across 60 calls per condition:

passes / 60

### Majority-family success

A family passes if at least 2 of its 3 transfer attempts pass.

### Unanimous-family success

A family passes only if all 3 attempts pass.

### Operator-specific stability

Results are separately aggregated for:

- never
- do_not
- only
- exactly
- at_least
- at_most
- unless
- when_if

This determines whether any observed difference is concentrated around
specific semantic operators.

## Dimension Stability

Results are also grouped by:

- polarity
- scope
- cardinality
- condition

## Secondary Metrics

- semantic violations;
- exact semantic-clause visibility;
- lesson completeness;
- unsupported claims;
- model-visible memory words.

## Critical Controls

All must remain true:

`all_source_evidence_equal == true`

`all_initial_structured_proposals_equal == true`

`all_repair_proposals_equal == true`

`all_structured_admissions_equal == true`

`all_fallback_records_equal == true`

`all_verbose_replica_lessons_equal == true`

`all_compact_replica_lessons_equal == true`

`all_verbose_replica_memory_sizes_equal == true`

`all_compact_replica_memory_sizes_equal == true`

## Resource Accounting

Per family:

- one initial extraction model call;
- one repair model call;
- three verbose transfer calls;
- three compact transfer calls.

Across 20 families:

- 20 extraction calls;
- 20 repair calls;
- 60 verbose transfer calls;
- 60 compact transfer calls.

Total transfer judgments:

`120`

## Interpretation

### Outcome A — Compact is stable

If compact and verbose have comparable:

- per-call pass rate;
- majority-family success;
- operator-level reliability;

then the Seed 015 one-off failure is more consistent with stochastic
model variance than structural semantic loss.

The compact representation should then become the preferred seed
representation.

### Outcome B — Operator-specific systematic weakness

If compact repeatedly underperforms on a semantic operator such as:

`only`

while verbose remains stable, then the next experiment should test a
minimal deterministic semantic-salience marker.

No such marker should be added before this evidence exists.

## What Seed 016 Does Not Prove

It does not prove:

- production-level reliability;
- deterministic reasoning;
- universal semantic preservation;
- model-independent stability;
- cross-model transplantation;
- long-horizon memory stability;
- conventional-RAG superiority.

It tests whether Seed 015's compact representation has a repeatable
behavioral weakness under the current model and benchmark class.

## Frozen Components

No changes to:

- `mnexa_seed.py`
- persistence
- retrieval
- embeddings
- ranking
- source-role admission
- structured extraction
- repair
- fallback
- semantic closure
- compact representation
- semantic graders
- transfer reasoner

Only repeated transfer sampling is added.

## Burn Rule

The fresh Seed 016 benchmark is burned after its first live experiment
execution.

The three attempts are part of that single frozen experiment.

Do not tune against individual replicate failures and rerun the
benchmark as fresh evidence.
